# 她 · Her AI Companion

一个运行在 Android 上、由电脑提供大脑的个人 AI 陪伴与手机助手项目。当前开发版：**0.9.88**。免费开放项目代码；模型、API、声音与外部服务并不因此免费或无授权要求。

## 能做什么

- Live2D身体区域点击/揉动、情绪表情、小动作和仅聊天显示的心情灯。
- 文字/语音交互、日语输入、按天完整归档和历史查看。
- 可配置的QQ/微信只读来源、当日增量摘要、事项优先级、完成/延期/原文查看。
- 经用户授权用无障碍或Shizuku操作手机；B站搜索/播放/全屏、准确联系人导航。
- 半身悬浮陪伴、主/浮窗共享对话与可选QQ记忆衔接。
- 本地/公网线路重连与固定恢复入口发现；电脑必须开机联网。

这些功能的可用范围不同：模型/本音/QQ/微信/识别/系统权限都需自己配置。不会下载仓库就自动拥有所有私人服务。

## 快速开始：先在电脑看界面

需要Node.js 24+。在仓库根运行：

~~~powershell
npm run setup
$env:DEEPSEEK_API_KEY = '你自己的API密钥'
npm start
~~~

另开终端运行 npm run pair，打开本地已配对页面。模型请读 phone-brain/model/README.md；运行库请先读 THIRD_PARTY_NOTICES.md，再运行 npm run assets -- --accept-third-party。模型没导入时聊天界面仍可使用，但不会凭空显示角色。不要将真实密钥写进提交。

## Android构建

用Android Studio打开根目录，安装JDK17/Android SDK34，Gradle8.9兼容AGP8.7.3。导入你有权自用的模型与运行库后运行 gradle :apk:assembleDebug。第三方依赖由Maven下载，不包含私人签名文件；生成的调试APK由你本机签名。**本仓库不提供包含作者公皮的公开APK。**

手机初次连接建议USB adb reverse tcp:8790 tcp:8790；使用本机生成的完整配对链接。局域网需自行把config.json的bind改为0.0.0.0、确认防火墙及配对；公网入口不保证永久可达。

## QQ/微信、声音与权限

account-roles.json中的10001/10002只是示例，主号和机器人必须分开。可选共享记忆适配器位于qq-bridge/src，只包含必要模块，不附QQ机器人、账号状态或凭据；没有QQ预算服务时可独立聊天。微信只读采集器需要自行配置受支持Windows微信和Python依赖，默认未启用。声音默认关闭，需配置你有权使用的本地服务和参考声音。请按需授予手机通知/无障碍/悬浮/麦克风/Shizuku等权限。

## 测试与项目结构

运行 npm test 执行可复现的纯逻辑与隔离数据回归；不向真人发送信息、不使用真实聊天。Android工具和视觉/真实平台验收范围不等于该命令。phone-brain是大脑和网页；apk是安卓源码；scripts是公开版安装工具。

开发时通过147项原逻辑、主/浮窗60项界面及真机断线/慢加载专项；这不是“没有bug”的保证。独立发布包还需通过本包自己的启动/依赖/隐私检查，以 release-review.md 为准。

### 本地导入模型

安装 Python 3.10+ 和 Pillow 后，可用 python scripts/import-model.py --source 你从作者取得的模型目录 --accept-model-license 导入，仅用于你自己的本机构建。工具不下载模型、不覆盖已有目录；保留作者许可并只对本地副本缩小纹理。导入工具会从你本地的原作者文件生成23种表情/8组动作与触摸适配，并保留作者许可；其他模型仍需另外适配。
